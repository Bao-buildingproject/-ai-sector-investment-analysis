# AI Sector Investment Analysis

A personal investment research project comparing selected AI-related
companies using financial statements and financial ratios I have
studied in the CFA Program.

## What I Will Do

- Collect financial statements and organize the data using SQL.
- Apply CFA-based financial analysis, including profitability,
  liquidity, leverage, efficiency, and cash flow ratios.
- Analyze financial performance and valuation using Python.
- Build a Power BI dashboard to compare companies.
- Write an investment report presenting key findings and risks.

## Goal

Identify financially stronger companies and assess whether their
valuations are supported by business performance.

**Tools:** Python · SQL · Power BI  
**Status:** In progress
